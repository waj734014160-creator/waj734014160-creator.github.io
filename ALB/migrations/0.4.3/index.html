    ALB 0.4.3 数值与输入门禁修复说明¶

    文档角色¶

    • 角色：0.4.2 到 0.4.3 的稳定修复与开发验证说明。
    • 允许更新：0.4.3 已实现边界、冻结参考、真实开发验证和明确延期项。
    • 禁止更新：核心算法替换、未执行的正式发布结论和外部实时状态。
    • 事实来源：0.4.3 源码、修复前冻结参考和实际 pytest/mypy 输出。

    版本边界¶

    Python 包开发版本升级为 0.4.3。JSON5 schema_version 和 surrogate package 格式继续使用 0.4.0。v0.4.2、原 wheel 和正式验收报告保持不变； 当前 0.4.3 尚未形成固定发布候选或标签。

    本补丁只修复会影响数值可信度或容易静默改变输入的四项边界，不替换静平衡 Newton、recognize_kc()、谐波线性化或液膜核心算法。

    修复内容¶

    • SimulationConfig 要求 rotor 为 dimensional，并在任何 owner reset 前读取 node 输出，验证其为含 uxy/uxyt 的有限 (node_count, 2) mapping。coupling 在 reset 和每次 advance 后再次验证输出；前者给用户构建期错误，后者保护 随时间变化的运行状态，两者验证的时点和职责不同。
    • 静平衡相对残差优先保留普通 np.linalg.norm() 结果；仅在普通范数下溢或 溢出时使用稳定 hypot 路径。归一化载荷模长为零或非有限时在 runtime 创建 前失败，不再把无定义相对误差解释为零。
    • JSON5 禁止对象重复键。bearing/simulation 的时间步不再接受字符串或布尔值， simulation 的 steps、mount node、history downsample/capacity 不再通过 int() 静默截断浮点数或布尔值。
    • surrogate fixed spool 在配置和 runtime 两层都限制为归一化 [-1, 1]， 与 external-spool 的 ValveOutput 边界一致。
    • SimulationConfig.loads 在配置边界一次性校验并深冻结；run() 不再承担 首次发现载荷类型或字段错误的职责。高层 bearing、equilibrium 和 simulation 只包装普通 Exception，KeyboardInterrupt 与 SystemExit 保持 Python 原生取消语义。
    • mixed-film runtime 删除逐属性、逐方法转发的 _film_solver 代理，改为薄 生命周期 mixin 直接叠加到原生 film solver。结构型“禁止多继承”测试删除， 保留量纲、节流器和无量纲三条行为/数值回归。
    • 单液膜用户结果新增明确命名的压力和膜厚只读数组；公开配置字段的含义、单位 和缺省值集中记录在 docs/api/bearing_config_reference.md，源码中的 film 字段定义成为校验与物化共用的单一名称映射。

    明确延期¶

    本轮不处理成功 simulation 的 isolated observer 诊断搬运和资源路径 containment。这些问题不改变当前有效数值路径，按独立 P3 维护范围处理。
