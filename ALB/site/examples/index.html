    完整配置示例¶

    以下 UTF-8 JSON5 文件由 integration smoke test 通过公开 facade 加载、构建并至少计算一次。它们不含机器绝对路径或 legacy key。

    量纲液膜¶

    下载 liquid_film_minimal.json5

    // Minimal dimensional liquid-film bearing; geometry and pressure use SI units.
{
  schema_version: "0.4.0",
  kind: "bearing",
  spec: {
    family: "liquid_film",
    unit_system: "dimensional",
    time_step: 0.001,
    node: 0,
    film: {
      circumferential_elements: 5,
      axial_elements: 3,
      max_iterations: 20,
      solver_tolerance: 1e-6,
      eccentricity: 0.0,
    },
    restrictors: null,
    thermal: null,
  },
}

    主动润滑 PID¶

    下载 active_lubricated_pid.json5

{
  schema_version: "0.4.0",
  kind: "bearing",
  spec: {
    family: "active_lubricated",
    unit_system: "dimensional",
    time_step: 0.001,
    node: 0,
    film: {
      circumferential_elements: 5,
      axial_elements: 3,
      max_iterations: 20,
      solver_tolerance: 1e-6,
    },
    restrictors: {
      positions: [[0.5, 0.25], [0.5, 0.5], [0.5, 0.75]],
      orifice_diameter: 0.002,
      orifice_length: 0.02,
      valve_area: 0.00000122,
      discharge_coefficient: 0.6,
    },
    tank: {
      x_range: [0.49, 0.51],
      z_range: [0.2, 0.8],
      depth_ratio: 2.0,
    },
    valve: {
      model: "second_order",
      natural_frequency_hz: 166.0,
      damping_ratio: 0.7,
      delay: 0.0,
    },
    control: {
      mode: "pid",
      frequency_hz: 50.0,
      sensor_angles_deg: [45.0, 135.0],
      gains: {kp: 1.0, ki: 0.0, kd: 0.0, feedforward: 0.0},
    },
    thermal: null,
    transforms: {},
  },
}

    代理轴承资源模板¶

    下载 surrogate_bearing.json5

    {
  schema_version: "0.4.0",
  kind: "bearing",
  includes: [],
  spec: {
    family: "surrogate",
    unit_system: "dimensional",
    time_step: 1e-4,
    node: null,
    model_package: {
      // Replace with a validated package created by create_model_package().
      path: "models/albnn_package",
      use_augment: false,
    },
    runtime: {
      parameters: {
        clearance: 8e-5,
        radius: 0.04,
      },
      spool_mode: "fixed",
      spool: [0.0, 0.0],
    },
  },
}

    需要用户资源

    这是经过 JSON5 结构检查的资源模板，不是独立可运行 smoke。请把 models/albnn_package 替换为实际 ALBNN model package，并按 package 合同补齐 runtime parameters 后再调用 load_bearing_config 或 bearing_from_file。

    ROSS Excel 仿真资源模板¶

    下载 simulation_ross_excel.json5

    {
  schema_version: "0.4.0",
  kind: "simulation",
  includes: [],
  spec: {
    rotor: {
      model: "ross_excel",
      // Replace with a real ROSS Excel model below this document directory.
      path: "resources/rotor.xlsx",
      frequency_hz: 50.0,
      alpha: 0.0,
      beta: 0.0,
    },
    time_grid: {
      time_step: 1e-4,
      steps: 1000,
    },
    mounts: [
      // Replace with real ALB 0.4 bearing documents.
      {bearing: "bearings/left.json5", node: 0},
      {bearing: "bearings/right.json5", node: 4},
    ],
    loads: [
      {type: "gravity", acceleration: 9.80665},
      {type: "static", node: 2, force: [0.0, -100.0]},
      {
        type: "unbalance",
        node: 2,
        phase: 0.0,
        t_max: 1.0,
        m: 0.0,
        freq: 50.0,
        e: 0.0,
        no_step: false,
      },
    ],
    history: {
      mode: "memory",
      fields: [
        "rotor_displacement",
        "rotor_velocity",
        "bearing_force",
      ],
      downsample: 1,
    },
  },
}

    需要用户资源

    这是经过 JSON5 结构与占位路径检查的模板。resources/rotor.xlsx 和两个 bearings/*.json5 必须由用户提供，且均须位于配置文件的资源根目录内；因此测试不会把该模板伪装成可直接构建的仿真。字段含义和结果形状见仿真配置参考。
